# 🚀 Quick Start - Flows Discovery Electron

## 5 minutes pour avoir l'app

### Étape 1 : Préparer (2 min)
```bash
# Télécharger Node.js si besoin
# https://nodejs.org/ (LTS)

# Ouvrir Terminal/PowerShell dans le dossier flows-discovery
cd flows-discovery
```

### Étape 2 : Installer (1 min)
```bash
npm install
```

### Étape 3 : Lancer (30 sec)
```bash
npm start
```

L'app s'ouvre ! 🎉

---

## Créer l'exécutable Windows (.exe)

```bash
npm run build-win
```

Trouvez le `.exe` dans le dossier `dist/`

Double-cliquez pour installer et utiliser sans Node.js !

---

## Utiliser l'app

1. **Email** : Votre compte ExtremeCloud
2. **Password** : Votre mot de passe
3. **🔓 Login** → **🔄 Load Appliances** → **Sélectionner** → **▶️ Launch Discovery**

C'est tout !

---

## Problèmes ?

| Problème | Solution |
|----------|----------|
| `command not found: npm` | Installer Node.js |
| Application lente au premier lancement | Normal, création du cache |
| Erreur de connexion API | Vérifier identifiants + réseau |
